# AGENTS.md

## Cursor Cloud — RigZIP

Premium commercial vehicle rental marketplace (US professionals). Frontend-first Vite + React + TypeScript.

### Commands

- `npm install`
- `npm run dev` → http://localhost:5174/
- `npm run build`
- `npm run lint`
- `npm run typecheck`

### Product (short)

- Dual-sided: rent (tenant) / list (owner)
- Commercial-only; MC/authority + insurance for renters
- Email OTP only (no Twilio/SMS)
- COI on renter policy for the trip; PTI gates handover
- Rates: hour (min charge) / day / week / month
- After-hours pickup, calendar, damage claim packs

### Design

Industrial premium: Syne + DM Sans, ink/steel + amber accent. Not the old RigZip-UAT catalog UI.

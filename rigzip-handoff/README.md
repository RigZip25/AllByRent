# RigZIP

Premium commercial vehicle rental marketplace for US professionals.

Rent or list trucks, trailers, and specialized equipment — with COI on the renter’s policy, PTI-gated handover, calendar, after-hours pickup, and owner tools.

## Stack

- React 19 + TypeScript
- Vite 8
- Vanilla CSS design system (no UI kit)

## Develop

```bash
npm install
npm run dev
```

App: [http://localhost:5174](http://localhost:5174)

## Scripts

- `npm run dev` — local server
- `npm run build` — production bundle
- `npm run lint` — oxlint
- `npm run typecheck` — `tsc -b`

## Product notes

Frontend-first greenfield. Backend, Stripe, VIN, Identity, and App Store wrap come next.
